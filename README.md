# Projeto-PET-Tele
Repositório criado para armazenar e permitir o controle de versões do protótipo de meu trabalho para o processo seletivo do grupo PET-Tele da Universidade Federal Fluminense, que é tutorado pelo professor Alexandre Santos de la Vega. 

O projeto tem como temática "Desenvolvimento de "webpages dinâmicas”" e seu protótipo consiste na criação de webpages para o grupo PET-Tele utilizando HTML, CSS, PHP e arquivos do tipo JSON.
